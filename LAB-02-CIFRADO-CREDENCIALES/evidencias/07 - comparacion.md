| Situación                                     | Mecanismo apropiado                                                                                                                | ¿Qué protege?                                                                                                                                                                                             |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Contraseña de usuario                         | Hash criptográfico unidireccional con sal (ej. `pgcrypto` con `crypt()` y `gen_salt('bf')`).                                       | Impide que la contraseña se almacene en texto plano. Protege contra la lectura directa en la base de datos y ataques por diccionario o tablas precalculadas (rainbow tables).                             |
| RFC almacenado en una tabla                   | Cifrado simétrico (ej. `pgp_sym_encrypt()`).                                                                                       | Protege datos altamente sensibles en reposo. Permite mantener la confidencialidad de la información ante accesos no autorizados a las tablas, permitiendo su recuperación legítima con la clave correcta. |
| Consulta enviada desde un cliente al servidor | TLS (Transport Layer Security) con un modo adecuado (`sslmode=require`, `verify-ca` o `verify-full`).                              | Protege los datos en tránsito, asegurando la confidencialidad, integridad y autenticación de la comunicación entre la aplicación o cliente y la base de datos frente a escuchas en la red (sniffing).     |
| Respaldo de una base de datos                 | Cifrado del archivo de respaldo (ej. `pg_dump` cifrado con GPG/AES o almacenamiento cifrado a nivel de disco o sistema operativo). | Protege la información sensible cuando se exporta o almacena fuera del servidor de base de datos activo, evitando filtraciones en medios de almacenamiento secundario o servicios en la nube.             |
| Clave criptográfica                           | Sistemas de gestión de secretos (ej. HashiCorp Vault, AWS Secrets Manager o variables de entorno restringidas).                    | Protege las llaves maestras y de cifrado para evitar que queden expuestas en el código fuente, archivos de configuración o repositorios de código (como Git).                                             |
