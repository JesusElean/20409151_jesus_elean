# Actividad 15 — Propuesta de arquitectura de datos protegidos
Diseña una propuesta conceptual para separar la información de acuerdo con su finalidad.

Puedes utilizar:

```

                 BASE DE DATOS
                       │
        ┌──────────────┼──────────────┐
        │              │              │
        ▼              ▼              ▼
     Operación      Analítica       Auditoría
        │              │
        ▼              ▼
  Datos necesarios   Datos
  para operación     agregados
```

```
                                    BASE DE DATOS
                                          │
                  ┌───────────────────────┼───────────────────────┐
                  ▼                       ▼                       ▼
            ESQUEMA OPERACIÓN        ESQUEMA ANALÍTICA       ESQUEMA AUDITORÍA
            (Soporte/Facturación)   (Business Intelligence)  (Seguridad/Compliance)
                  │                       │                       │
       ┌──────────┴──────────┐            ▼                       ▼
       ▼                     ▼      Vistas Agregadas      Logs de Accesos y
  Soporte             Facturación   y Disociadas           Modificaciones
  (Id, Nombre,        (Id, RFC,     (Metricas por          (Inmutable, pgaudit,
   Correo, Tel)        CP, Total)    Ciudad/Edad)           Solo Lectura)
```

Agrega controles para:
* acceso
* minimización
* protección de información sensible
* retención
* trazabilidad
* eliminación
* atención de solicitudes

No es necesario implementar físicamente toda la arquitectura.

El objetivo es demostrar que puedes **traducir principios de privacidad a decisiones técnicas**.
